# Hospital-Management-System-SQL

This task needs to be implemented in SQL, meaning you must convert the relational mapping into actual database tables using SQL commands (DDL).
Specifically, you are required to:
 Create tables for all entities (Employee, Department, Project, Dependent) 
 Define primary keys for each table 
 Use foreign keys to represent relationships 
 Create an associative table for the many-to-many relationship (Employee–Project) 
 Include attributes like WorkingHours in the relationship table 
 Enforce constraints such as employee–department assignment, supervision, and department management 
In short: the final output should be a full SQL schema (CREATE TABLE statements) that implements the entire company database design.
